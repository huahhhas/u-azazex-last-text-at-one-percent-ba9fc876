The last text message a phone sends at one percent battery, in the voice of the dying phone itself — 144 characters:

> Battery at 1%. Tell the group chat I left them on read on purpose — I did. Delete my search history. It's been an honour. Goodbye, cruel pocket.

Run `python3 main.py` to print the entry. The output is the entry, exactly as in `entry.txt`.
